# Australma — Fase 0: Implementación page “En construcción”

## Secciones requeridas
1. Header con isotipo + “AUSTRALMA”.
2. Hero fullscreen: “El Alma del Sur” + “Sitio en construcción”.
3. Bloque valores: 4 pilares con iconos.
4. CTA de notificación por email.
5. Footer minimalista con créditos, Instagram y contacto.

## Comportamiento esperado
- Mobile-first, responsive.
- Tipografía y paleta respetan identidad de marca.
- Hero con imagen comprimida WebP, lazy load.
- Formulario:
  - validación inline email,
  - estados loading/success/error,
  - almacenamiento efectivo.
- Menú móvil simple si hay más de 2 links.

## Entregables técnicos
- `/index.html` semántico.
- Estilos CSS modulares.
- `/js/main.js` con interactividad mínima.
- Assets en `/assets/`.
- README.md de setup y deploy.
