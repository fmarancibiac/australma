# Australma — Fase 0: Documento de diseño web senior

## Tipo de página
Landing one-page “En construcción”.

## Tokens visuales
- Verde austral: #123628
- Azul profundo: #0D1B2A
- Dorado premium: #C49A2C
- Arena natural: #F3EDE0
- Grafito: #232323
- Títulos: Trajan / Montserrat bold
- Cuerpo: Montserrat
- Escala: H1 ~3.2rem, H2 ~2rem, body ~1.125rem
- Line-height: 1.5

## Mapa de secciones
1. Header fijo con isotipo + AUSTRALMA y nav mínima.
2. Hero fullviewport con lema y CTA.
3. Sección valores con 4 pilares.
4. Sección captura leads.
5. Footer minimalista.

## Componentes
- Header: isotipo SVG + nombre, fondo oscuro, separador dorado, nav colapsable en mobile.
- Hero: imagen de fondo comprimida + overlay oscuro, título grande, subtítulo.
- Valores: grid 1/2/4 columnas, iconos SVG, título pequeño + cuerpo corto por tarjeta.
- CTA: input email + botón principal, validación inline, estados idle/loading/success/error.
- Footer: fondo oscuro, texto arena, Instagram, contacto y legal con hover dorado.

## Responsive
- Breakpoints: 320px, 390px, 768px, 1024px, 1440px.
- Mobile-first.
- Tipografía fluida 1rem a 1.25rem.
- Hero sin scroll horizontal.
- Componentes con min-height util.

## SEO básico
- Title y meta description únicos.
- OG title, description e image.
- Favicon + apple-touch-icon.
- Sitemap.xml y robots.txt.
- HTML semántico: header, main, section, footer.
- Alt text en imágenes.

## Assets requeridos
- Isotipo SVG claro y oscuro.
- Favicon SVG/ICO.
- Hero WebP comprimida.

## Tono de copy
- Premium, preciso, sin exceso.
- Naturaleza, propósito y durabilidad.
- Formalismo de marca, sin slang.

## Definition of Done
- Mobile-first validado en 320px/1024px.
- Contraste AA verificado.
- Componentes consistentes con tokens.
- SEO on-page verificado.
- Assets identificados.
