# Australma — Fase 0: Contexto del proyecto

## Resumen
Australma es una marca premium chilena de productos inspirados en la naturaleza austral. Necesita presencia web inmediata antes del lanzamiento comercial.

## Entregable de esta fase
Una página one-page “En construcción” alojada en `australma.cl` o `www.australma.cl`.

## Objetivos específicos
- Respetar el manual de identidad visual adjunto.
- Primera presencia indexable en Google.
- Capturar leads (email) para notificar lanzamiento.
- Sentar stack base para fases siguientes.

## Alcance
- Landing page responsive.
- SEO básico.
- Formulario de notificación.
- Deploy con HTTPS.

## Fuera de alcance en esta fase
- Catálogo, blog o ecommerce.
- Pasarelas de pago.
- Producción multimedia.
- Hosting administrado.

## Assets disponibles
- Logos e isotipos en `/humano/` y `/Australma/Australma Logos/`.
- Guía de identidad de marca PNG en `/Australma/Guía de identidad de marca Australma(2).png`.
- Paleta y tipografía definidas en el brief PDF.
